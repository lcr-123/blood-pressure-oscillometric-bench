# 跨天批次协议修订 1：面板切换重试（2026-11-16）

本文件修订 `reference_bp_batch_crosstday_v1.md` 的一条编排规则。协议 §7 与附录 A 的
铁律是「批次期间不得改任何脚本。若必须改，本批次在改动日终止，按 §4 记账，剩下的天数
归下一次预注册」。**本修订走的就是这条路径**：v1 在改动日终止，改动日之前没有记录任何
完整天（见 §3），因此 v1 的产出为零；本修订随一份新的预注册重新开始，D1 从 2026-11-16
傍晚起算。

判定规则 T0–T4、排除规则、每日仪表卡片五项、以及「不得做的五件事」全部不变。只改
「一个切换命令没应答怎么办」这一条。

## 1 改了什么

| | v1 原文 | 本修订 |
|---|---|---|
| 切换窗口 | `bp_preset_remote.REQUEST_WAIT_S = 3.6 s`，且 `drain()` 读到窗口耗尽才返回 | 12 s，但**读到首字节就返回**，健康切换仍约 0.55 s |
| 失败处理 | 一次不 ACK 立即 `SystemExit(3)`，整天终止 | 用**同一条** `[SIM_STD*]` 最多重试 3 次，间隔 2 s；3 次都不 ACK 才终止 |
| 记录 | `panel_state_established` + `panel_switch_reply` | 另加 `panel_switch_attempts`（每次的 reply 与字节数）与 `panel_switch_policy`（窗口/次数/间隔/修订号） |
| 每轮 `orchestrator_sha256` | 硬写 `None` | 改为真实哈希，与日级 manifest 一致 |

**只重发同一条命令**，这一点是刻意的：若某次 ACK 迟到、面板其实已经切成功，再发一次
同档命令不会把面板移到别的档；因此「记录的面板标签」与「实际面板」不可能因重试而错配。
若重试最终失败，该档不采、当天终止，与 v1 的行为一致。

## 2 为什么要改（2026-11-16 的实测证据）

D1 当天用 v1 跑，块A 三次全部成功（14/14 轮 `gate=USABLE`），但**四次**死在一个
`[SIM_STD*]` 没应答上，其中三次是某个块的第一个切换：

| 时刻 | 位置 | 之前静默 | 结果 |
|---|---|---|---|
| 13:50:29 | 块A 第 1 档 | 手动探测之后 | `[SIM_STD120_80] NO REPLY` → 终止 |
| 15:18:23 | 块B 第 1 档 | 19.5 min（块A 采集期间） | `[SIM_STD120_80] NO REPLY` → 终止 |
| 16:23:25 | 块B 第 1 档 | 5.4 min | `[SIM_STD120_80] NO REPLY` → 终止 |

每次失败后，**同一端口立刻手动重试都是 0.06–0.12 s 就 ACK**（远快于健康时的
0.53–0.59 s），说明 Tester 从未死掉，是那一条应答丢了。

为定位触发条件做了七组探针，全部为只读、不改泵阀状态：

| 探针 | 做了什么 | 结果 |
|---|---|---|
| `tmp/late_reply_probe_20261116.py` | 30 次连切，20 s 窗口 | 30/30 ACK，首字节 0.53–0.59 s（一次 2.74 s） |
| `tmp/rewrap_gap_repro_20261116.py` | 重开端口 + 静默 320 s + 切换，2 轮 | 首个切换 0.57 s ACK，零丢失 |
| `tmp/port_held_switch_probe_20261116.py` | 端口跨 2 次真实采集 + 静默 300 s | 两个切换 0.57/0.53 s ACK，零丢失 |
| `tmp/silence_duration_probe_20261116.py` | 25 次连切，5 s 窗口 + 至多 6 次重试 | 25/25 ACK，无静默事件 |
| `tmp/link_monitor_20261116.py` | 14 min × 388 次 `[BP_VERSION]` ping | 零静默 |
| `tmp/stale_reply_probe_20261116.py` | 故意用 1.0 s 窄窗 | **抓到**：第 2、3 轮切换后连 `[BP_VERSION]` 都静默满 12 s |
| `tmp/tester_sleep_probe_20261116.py` | 长静默后三连击 | 未跑到（被 D1 重跑占用端口） |

结论：静默是**间歇**的，不是由静默时长、端口持有或采集活动单独触发；窄窗能抓到它，宽窗
抓不到是因为样本不够。**因此「一次不应答就判面板不可确立」这条判据本身站不住**——它把
一个几秒钟的链路抖动升级成「整天作废」。
