# 传感器供电告警——已解除（面包板线松），但我当时的推理有三处错误

日期 2026-11-10。原告警文件是 `sensor_supply_alert_20261110.md`，**本文取代它**。
结论：**是面包板上的线松了，重新插好后完全恢复正常，不是供电跌落。**
但我在排查过程中做了两个不成立的推断，必须记下来。

## 一、发生了什么

| 时刻 | 状态 |
|---|---|
| 17:56 | 健康：`sensor` 253–254 mV，`raw p2p` 3 counts |
| 18:1x | 异常：`sensor` 122 mV，`raw p2p` 99–104 counts，`true = −11.3 mmHg` |
| 18:2x | 用户发现是**面包板上的线松了**，重新插紧 |
| 18:3x | 恢复：`sensor` 221 mV，`raw p2p` 3–9 counts，`true = −1.69 mmHg` |
| 之后 3 分钟 | 稳定在 217–224 mV，噪声 6–19 counts |

## 二、我的错误一：把"三个量同比例下降"当成三条独立证据

我写了：

> `sensor`、`ads`、`raw` **三个量按同一个比例（0.46–0.48）下降**，与比率式传感器的
> 供电跌落完全一致。

**这是错的。** 这三个量是链条关系：

```
ads = raw × 0.125 mV
sensor = ads × 1.3799     （分压比）
```

验证：`705 × 0.125 = 88.1`（报告 88.0）、`88.0 × 1.3799 = 121.4`（报告 122.0）。

**所以"三个量同比例下降"其实是同一个数被写成三种单位**，只提供了一条证据，
不是三条。

## 三、我的错误二：拿 `sensor/ads = 1.3799` 当"分压链完好"的证明

我在告警里写：

> `sensor/ads 比值 = 1.3793`（设计值 1.3799），分压比完好。

**这个比值是电阻分压决定的常数，无论供电跌了还是零点漂移了，它都还是 1.3799。**
它只能证明"分压电阻和 ADC 没坏"，**不能区分供电跌落与零点漂移**。

能区分两者的量是这个：

| 假设 | 零点 | 量程（斜率） |
|---|---|---|
| 零点漂移 | 移动 | **不变** |
| 供电跌落（比率式） | 按比例压缩 | **同样比例压缩** |

我一次都没测量程就下了"供电跌落"的结论。

## 四、我的错误三：把 242 mV 当成唯一合法零点

告警里写"健康零点 242 mV，现在 122 mV，所以 VS = 2.52 V"。

但 `data/reports/dataset_limitations.md` 早就记着：**21 轮封阀零点在 −2.23 … +1.35 mmHg
之间**，跨度 3.58。换成 `sensor` 读数：

| `sensor` | 真实压力 | 在历史零点范围内？ |
|---|---|---|
| 122 mV（线松时） | −9.84 | **否**（确实异常） |
| 220 mV（重插后） | −1.78 | **是**（正常漂移） |
| 242 mV（标定锚点） | +0.04 | 是 |

**所以：线松时确实异常，但重插后的 220 mV 完全正常。** 我把 242 mV 当作唯一有效值，
导致我一度把正常状态也判成故障。

## 五、那个"280 mmHg 保护会失效"的推算为什么是错的

我当时算：若 VS 跌到 2.52 V（k = 0.504），固件读数压缩，`target 275` 实际可能是 545 mmHg，
280 保护要到真实 575 mmHg 才触发。

**这个推导本身在数学上没错，前提（VS 跌到 2.52 V）是错的。** 现在 `sensor` = 221 mV，
对应 VS ≈ 4.57 V（按 242 mV ↔ 5.0 V 的比率），量程未压缩。

**旁证**：恢复后跑了一次 30 mmHg 低压试充（`tmp/lowtarget_probe_20261108.py 30`）：

```
baseline  sensor 220 mV  est 0.0
after     sensor 468 mV  est 18.6   raw change +1435 counts = +20.38 mmHg
```

若量程真被压缩 0.504 倍，同样的真实压力只会让固件读数变成约 **5.5 mmHg**，而不是 20.38。
**所以量程完好。**

## 七、教训

**告警要发，但告警里的因果推断必须和告警本身分开写。** 我当时把"读数异常"（事实）
和"供电跌到 2.5 V"（推断）写在同一层，读者会以为两者同样可信。

正确的做法是：先说"读数异常，停止充气"，再单独写"候选解释与各自的判据"，
并明确哪个判据还没测。**这次我漏掉了量程这一项，而它恰恰是唯一能区分两种假设的量。**
