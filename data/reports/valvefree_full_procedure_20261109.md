# 阀外方案全流程（BP Pump 2 + 袖带 + 注射器，不用阀不用 MCU）

日期：2026-11-09
目的：用 BP Pump 2 的**独立压力传感器**测出袖带回路的气体容积，作为数据集 `cuff_volume_cc` 的实测依据。
全程约 15 分钟，其中动手 5 分钟、等待 6 分钟、恢复 3 分钟。

**你的角色**：拆管、接注射器、在面板上按键、抄 4 个数字。
**我的角色**：算容积、判读、写进报告和元数据。我不碰硬件、不发串口命令。

---

## 阶段 0：准备清单（动手前先凑齐）

| 项 | 要求 | 没有会怎样 |
|---|---|---|
| 20 mL 注射器 | 带鲁尔接头，能插进三通 | — |
| 三通 / T 型接头 | 一个，与现有软管同口径 | 无法并接袖子 + 注射器 |
| 扎带 ×2 或弹簧夹 | 能把推杆压在筒口法兰上 | 活塞在 200 mmHg 下 0.85 kgf 会自己爬出去，容积全错 |
| 手机 | 计时用（或用面板时钟） | 4 个时刻无法记录，漏气修正失效 |
| 纸笔 | 抄 P0 / P0b / P2 / P2b | — |
| 气压计 | 手机天气 App 的当地气压即可 | 用 760 会有 ±20 mmHg 系统误差，见第四节 |

## 阶段 1：拆气路（约 3 分钟，断电或至少 vent 完成）

1. **先确认无压**：面板 `VENT`，或确认 MCU 已 `vent`（`pins` 显示 `PC1=HIGH`）。
2. 把**袖带软管从现有三通上拔下来**。
3. 袖带软管 → 接到**三通的一个口**。
4. 三通第二个口 → 接 **BP Pump 2 的 Pressure Port**（前面板那个压力口）。
5. 三通第三个口 → 接 **20 mL 注射器**，活塞推到 **0 mL 顶到底**。
6. **检查**：所有接口插到底、无松脱；注射器鲁尔头要推进去，不能只是搭在口上（历史上漏气就出在这里）。

**这一阶段的电路是这样的：**

```
BP Pump 2 Pressure Port ──┬── 袖带（缠在硬芯上，不拆不重绑）
                          └── 20 mL 注射器（活塞在 0，顶到底）
```

**阀1、阀2、气泵、MCU 全部不参与。** 它们连同各自的三通一起留在旁边不接，这是本次方案的
关键简化：阀2 那个 6.5 mmHg/min 的漏点从回路里消失了。

**⚠ 注意**：袖带一旦拔下来重新接，**缠绕状态可能变了**。所以这次测完，下一次采数据集前
必须重新绑一次并且重测 —— 这条我会写进报告的"副作用"。

## 阶段 2：面板设置（约 1 分钟）

1. `HOME` → **`PRESSURE TESTS`**
2. → **`STATIC PRESSURE`**
3. → **`SOURCE`**
4. → **`SETUP`**
5. 屏幕出现 `Pressure Source / Setpoint: 200 / mm Hg`
6. 数字键输入 **`200`**（若已是 200 可跳过）
7. 按 **`ENT`**
8. 出现 `Pressure Source` 屏：`Measured: 0.x / Setpoint: 200`，下方软键 `GAUGE | SETUP | VENT | <START>`
9. 按 **`VENT`**（放空约 5 秒），确认 `Measured` 回到 0 附近

> **依据**：手册 `PRESSURE TESTS → STATIC PRESSURE → SOURCE → SETUP`，Setpoint 默认 200，
> 压力范围 50–400 mmHg，加压后到达设定值 ±10 mmHg 就停。

## 阶段 3：加压并测 4 个读数（约 6 分钟）

### 关键原则：**90 秒 + 60 秒，两次读数**

**为什么必须等 90 秒**：手册明确"达到 Setpoint 后不再维持压力"，所以压力会持续下降。
下降有两个来源——漏气（可修正）和气体降温（不可修正）。

我们自己的历史数据（恒容、200 mmHg 起）：

| 历时 | 读数 | 掉了 | 速率 |
|---|---|---|---|
| 0 s | 201.2 | 0 | — |
| **90 s** | 170.5 | 30.7 | 20.5 /min |
| 120 s | 167.5 | 33.7 | **6.0 /min** |

前 90 秒里只有 9.8 mmHg 是漏气，**其余 21 mmHg 是压缩热**。90 秒后速率降到 6.0/min，就是纯漏气了。
**提前读会把 21 mmHg 的热误差当成压力，容积全错。**

### 时间表

按 `<START>` 的瞬间开始计时（用手机秒表）。

| 时刻 | 动作 | 记录 |
|---|---|---|
| **T+0** | 按 `<START>`，等压力爬升到 200 附近停住 | — |
| **T+90 s** | 读 `Measured` | **P0**，记时刻 **t0** |
| **T+150 s** | 再读一次（中间什么都不动） | **P0b**，记时刻 **t1** |
| **T+150–155 s** | 松开扎带 → **2–3 秒内匀速拉到 20 mL** → **立刻扎带/夹子夹紧推杆** → **两手离开台面** | — |
| **T+240 s** | 读 `Measured` | **P2**，记时刻 **t2** |
| **T+300 s** | 再读一次 | **P2b**，记时刻 **t3** |
| **T+300 s 后** | 按 `VENT` 放空 | — |

### 每一段为什么这么做

- **P0 → P0b（60 秒）**：两点确定一条直线，斜率就是该状态下的漏气率。**这是把漏气从"干扰"变成"已知量"的唯一办法。**
- **拉 20 mL**：给公式一个够长力臂（20 mL 对 166 cc 是 12% 容积变化）。
- **2–3 秒匀速拉**：太快把压力波变成振荡；太慢等于把漏气混进阶跃。
- **夹住 + 松手**：200 mmHg 下活塞受力 0.85 kgf。手按住时实测噪声 4.7 mmHg，松手只有 0.27 mmHg，**差 17 倍**。
- **P2 → P2b（60 秒）**：确认漏气率在拉完之后没变（若变了说明夹子松了或有新漏点）。
- **90 秒等待**：拉活塞使气体膨胀降温（理论降温 13 K、读数偏低 38 mmHg），必须等回温。

### 抄数格式（照这个报给我）

```
当地气压（手机天气）：______ hPa  ≈ ______ mmHg

t0 = ____ s   P0  = ______
t1 = ____ s   P0b = ______
t2 = ____ s   P2  = ______
t3 = ____ s   P2b = ______
```

> 时间只要落在设计值附近就行（例如 90/150/240/300），**如实报实际值**，我按实际时刻外推。

## 阶段 4：怎么算（我做的部分）

```
P1_abs·(V + g1) = P2_abs·(V + g2)      →   V = (P2_abs·g2 − P1_abs·g1) / (P1_abs − P2_abs)
```

其中 `P_abs = 面板读数 + 当地大气压`，`g` 是注射器刻度（0 和 20 mL）。

关键：**两个状态的压力都要先外推到同一个时刻**（拉活塞那一刻），否则要么高估、要么低估。
刚才我用一组示例数（193/187/78/72）验证过流程：

| 算法 | 结果 |
|---|---|
| 直接拿两个末读数（不修正） | 144.7 cc |
| **两段各拟合直线、外推到拉的那一刻** | **169.4 cc** |

**差 25 cc = 15%。** 这就是为什么必须要 4 个读数而不是 2 个。

工具已就绪：

```
python tools/valvefree_volume_analysis.py --p0 193 --p0b 187 --t0 90 --t1 150 \
    --p2 78 --p2b 72 --t2 240 --t3 300 --g1 0 --g-pull 20
```

它会输出：
- 两个状态的漏气率（应接近，差 >30% 会警告）
- 拉那一刻的两个压力
- 修正后与前后的容积
- 量化误差（整数显示只贡献 ±1.5 cc）
- 大气压敏感度
- **罐体在不在回路的判定**
- 袖带气囊容积 = V − 20 cc（主气室）− 6.5 cc（管路）

## 阶段 5：判读（三种可能结果）

### 情况 A：V ≈ 160–180 cc → 与既有估计一致

- 袖带气囊 ≈ V − 26.5 ≈ **135–155 cc**
- 数据集回路 ≈ **150–170 cc**
- 与气体定律的 158 cc、漏气比的 109–219 cc 全部重叠
- **`cuff_volume_cc` 可以填实测值 + 不确定度**，振幅换算从此有据可依

### 情况 B：V ≈ 450 cc 左右 → 290 cc 罐体开在回路里

- 说明 STATIC SOURCE 模式也带着罐体，我之前的推断错了
- 必须扣 290 cc，而 290 是标称值，不确定度大
- 结论退化为：**只能给出上界**，元件级拆分写 null

### 情况 C：V 明显偏离（<120 或 >600）→ 说明接错或漏气

先查四件事：注射器鲁尔头是否插到底、三通是否漏、扎带是否真夹住、拉的过程中压力有没有先升后降。
不追求"测出一个数"，先追求"测出一个自洽的数"。

## 阶段 6：恢复（约 3 分钟，必须做）

1. `VENT` 放空到 0
2. 拆掉注射器，**保留三通或恢复原接法**
3. 袖带软管插回原三通 → 接回 MCU 侧
4. 上电后查状态：
   ```
   status → cal=VALID ads=ONLINE stream=ON
   pins   → PB8=HIGH PC1=LOW PC8=HIGH pump=OFF
   ```
5. 确认零点：真实压力应在 ±2 mmHg 内（用 `python tmp/state_check_20261108.py 恢复后检查`）

> **因为袖带被拆过、缠绕可能变了，恢复后不要直接采数据集轮次。** 先跑一轮看包络峰位置是否
> 仍落在面板 MAP 附近，确认没变再继续。
