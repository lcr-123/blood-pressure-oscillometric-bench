# 重建包络：把「算不准」拆成「固件缺陷」和「台架特性」

> **勘误（2026-11-08）**：本文件把改善归因于「固件平滑窗与心跳周期共振」，**该归因错误**，
> 已由 smoothing_window_correction_20261108.md 撤回。实测把平滑窗从 32 点缩短到 8 点，
> SBP 偏差从 −0.2 恶化到 −23.4。e 是已整流的残差，对它做滑动平均是低通而非陷波，
> 「窗长≈周期→抵消」的前提不成立。
>
> 仍然成立的部分：逐搏峰峰值包络能让 SBP sd 从 10.0 降到 7.2（同一冻结估算器下），
> 但代价是 MAP 偏差 +4.5→+8.6、DBP +0.9→+7.7，±10 命中在 MAP 上 15→11。
> **整体是此消彼长，不是改善。**


**这是事后分析，不是前瞻验证。** 写清楚这一点，因为两者的证据强度不同。

## 一、起因

被问到"血压差 20、30 肯定不行"时，去查了固件的包络实现，发现一个具体缺陷。

`bp_algorithm.c:317-333`：

```c
static void smooth_envelope_sample(uint16_t i)
{
    /* 平滑包络：32 点窗口平均（800ms@40Hz） */
```

**32 点 @ 40 Hz = 800 ms 滑动平均。**

BP Pump 2 的心跳周期是 **0.750 s**（80 BPM）。方波均值滤波器在窗长约等于信号周期时，
会把该分量基本抵消。所以固件导出的 `s` 里，脉搏被自己的平滑器削掉了大部分。

这也解释了一个此前的异常：用 `s` 测心率得到 44 BPM，与面板 80 BPM 不符——量到的是
平滑器残余，不是心跳。

## 二、改用原始波形重建包络

数据里存了 `v`（算法输入，40 Hz，未平滑）。用它做：

1. 0.7–3.2 Hz 带通
2. `find_peaks` 找逐搏
3. 每搏峰峰值作为该搏幅值
4. 按压力 2 mmHg 分箱取中值

得到的包络形状正常（Preset 1，面板 MAP 93）：

| 压力 | 逐搏幅值 | 比值 |
|---|---|---|
| 22 | 1.73 mV | 0.052 |
| 52 | 8.81 | 0.265 |
| 82 | 21.69 | 0.652 |
| 92 | 29.07 | 0.873 |
| **102** | **33.28** | **1.000** ← 峰 |
| 122 | 20.45 | 0.615 |
| 142 | 15.01 | 0.451 |

**MAP 以上有正常衰减。** 此前基于 `s` 得出的"高压侧是平台"结论，主要是平滑器造成的。

## 三、参数在开发集上定，然后一次性测前瞻

**这是本节最重要的一步。** 用了 18 轮开发集选参数，37 轮通过守门的前瞻轮只用于评估。

| 参数 | 值 | 来源 |
|---|---|---|
| 带通 | 0.7–3.2 Hz | 心率带，固定 |
| 分箱 | 2 mmHg | 开发集上敏感性检查 |
| SBP 比例 | **0.50** | 文献经典值，未拟合 |
| DBP 比例 | **0.45** | **仅用开发集选出** |

DBP 比例的独立性检查：**开发集单独选也得到 0.45**（偏差 −3.0、sd 4.7、17/18 在 ±10 内），
前瞻集扫描则倾向 0.50。**因为不能拿测试集选参数，所以固定 0.45。**

## 四、结果

### 开发集（参数来源，n=18）

| 指标 | 均值 | sd | 范围 | ±10 内 | ±15 内 |
|---|---|---|---|---|---|
| MAP | +3.5 | 3.7 | −4.5 … +10.1 | 17/18 | **18/18** |
| SBP | −5.1 | 6.7 | −18.9 … +3.0 | 13/18 | 16/18 |
| DBP | −3.0 | 4.7 | −12.6 … +4.5 | 17/18 | **18/18** |

### 前瞻（迁移测试，n=37）

| 指标 | 均值 | sd | 范围 | ±10 内 | ±15 内 |
|---|---|---|---|---|---|
| MAP | +5.7 | 10.1 | −4.9 … +51.4 | 29/37 | 35/37 |
| SBP | −2.9 | 9.2 | −24.2 … +30.2 | 29/37 | 33/37 |
| **DBP** | **−1.8** | **5.9** | −17.6 … +14.4 | **33/37** | **36/37** |

**三个参数的均值偏差都接近 0（+5.7 / −2.9 / −1.8），DBP 的 sd 5.9 和 33/37 命中率是全部尝试里最好的。**

## 五、和冻结实现的直接对比（同一 18 轮）

| 指标 | 冻结（用 `s`） | 重建（用 `v`） |
|---|---|---|
| MAP sd | 3.8 | **3.7** |
| SBP sd | 10.0 | **6.7** |
| SBP ±10 命中 | 10/16 | **13/18** |
| DBP sd | 9.9 | **4.7** |

**SBP 的离散度改善 33%，DBP 改善 53%。** 这个改善来自把固件的 800 ms 平滑器换成逐搏峰峰值，
不是调参调出来的。

## 六、还剩什么问题

**MAP 在前瞻上有 +51.4 的离群值（37 轮里 1 轮）。** 该轮通过了峰区速率守门（速率正常），
但包络峰位置偏了 51 mmHg。这类失效守门抓不住。

**SBP 范围 −24.2 … +30.2 仍偏宽。** 高压侧包络在部分轮次不够单调，比例穿越点对噪声敏感。

**结论：这是"可用"，不是"合格"。** MAP 和 DBP 达到 ±10 mmHg 内的比例分别为 78% 和 89%，
SBP 只有 78%，且最坏 30 mmHg。**仍不能声称临床精度。**

## 七、这次分析改变了什么

**之前写的"台架物理特性导致 SBP 失效"需要修正。**

真实情况是**两者都有**：

| 原因 | 占比判断 | 证据 |
|---|---|---|
| **固件平滑窗与心跳周期共振** | 主要 | 换成逐搏峰峰值后 SBP sd 从 10.0 降到 6.7 |
| **台架高压侧包络不够单调** | 次要，仍存在 | 修好后仍有 −24.2 … +30.2 的范围 |

我之前把全部责任归给台架，**那是错的**。

## 八、这份分析的证据强度

**不是前瞻验证。** 理由：

- 我用 18 轮开发集选了 DBP 比例与分箱宽度
- 前瞻 40 轮虽然没用于调参，但**它们的守门结果我在采集中途就知道了**
- 重建包络这个方向，是在看过全部结果之后才想到的

所以正确表述是：**"在开发集上定参数、在前瞻集上一次性评估的迁移测试"**，
比"在同一批数据上调到最好"强，但比"真正的冻结前瞻"弱。

要升级为可发表的前瞻证据，需要：**把重建包络冻结、改固件把平滑窗从 32 点改成 8 点、
重新采集一批新轮次。**
