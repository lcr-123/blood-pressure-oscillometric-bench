# 用 20 mL 刻度做起点：三个平台都读得清

## 一、你的想法是对的

**从"满"（约 28 mL）做起点有个问题：那个位置没有准确刻度。**

**从 20 mL 开始，然后推到 10、推到 0 —— 三个位置都有印刷刻度，读数才可信。**

## 二、新的三个平台

| 平台 | 活塞刻度 | 预期压力（若回路 158 cc） |
|---|---|---|
| P1 | **20 mL** | **120 mmHg** |
| P2 | **10 mL** | **约 172** |
| P3 | **0 mL** | **约 231** |

**起始压力选 120，最高推到 231，远低于传感器 375 上限。**

（如果你现在的满位是 28 mL，那就是先往里推 8 mL 到 20 mL 刻度。）

## 三、为什么这样能出可信结果

**三滴水平台 → 三个方程对，每个都独立算一次 V：**

```
V = (P_b × g_b − P_a × g_a) / (P_a − P_b)

P1→P2：(930×10 − 880×20) / (880 − 930)
P2→P3：(991×0  − 930×10) / (930 − 991)
P1→P3：(991×0  − 880×20) / (880 − 991)
```

**三个数一致 → 容积被真正测出来；不一致 → 说明某个刻度或压力读错了。**

**而且因为 g 是实测刻度，活塞在 P1 时刻是否偏移会直接体现在 g1 里，不再需要假设。**

## 四、推入时的锁定（方向这次对了）

**推入让气体压力把活塞往**外**顶，所以：**

| 做法 | 有效性 |
|---|---|
| **刚性垫块顶住推杆头**（不是垫在法兰之间）| ✓ 正确 |
| 扎带做拉力约束 | ✓ 也可以 |
| 手按 | ✗ 之前实测漂 8–9 mL |

**垫块放在推杆头的**外侧**，让它承受向外的推力。**

## 五、操作顺序

| 步 | 谁 |
|---|---|
| 1 | **你把活塞推到 20 mL 刻度，先别锁** |
| 2 | 告诉我"好了" |
| 3 | 我 `vent`→`seal`→加压 120→冻结→等 90 s→读 **P1** |
| 4 | 我提示"推到 10 mL"，**你推入 10 mL 并用垫块顶住** |
| 5 | 我读 **P2**，提示"推到 0" |
| 6 | **你推到 0（推到底）并顶住** |
| 7 | 我读 **P3**、算三个 V、`vent` |

**全程约 5 分钟。**
