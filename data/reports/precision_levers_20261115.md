### 1.2 剩下那两格：不是"差一点没过"，是"判不了"

P5 的 SBP 均值 +5.15、P7 的 +5.05，门槛是 5.0——超线 0.15 与 0.05。
这两个数字看上去像"再采几轮就过了"，实际正相反。
`python tools/sbp_mean_ci.py`（入库，只做区间与功效算术，不读语料、不跑估算器）：

|---|---|---|---|---|---|---|---|---|

| P7 SBP | 36 | +5.05 | 6.46 | 1.077 | **[+2.86, +7.24]** | **是** | 0.05 = **0.05 SE** | 2.19 |

两点后果，都必须写清楚：

1. **超线量比置信区间半宽小一个数量级**（0.15 对 1.65；0.05 对 2.19）。
   在 n=39/36 上，这两个格与"恰好等于 5.0"在统计上不可区分，
   所以对它们诚实的表述是**"未判定"（not resolved）**，而不是"FAIL"。
2. **加轮次并不能把它们变成 PASS**。观测到的均值本身就在 5.0 以上，
   置信区间只会**围绕这个观测均值收窄**，不会跨到门槛下方——
   把区间半宽减半需要约 **156 / 144 轮**（4 倍样本量），
   而半宽减半后区间仍然是 [+4.32, +5.97] 与 [+3.95, +6.14]，**依然含 5.0**。
   要真正把这两个格判成 PASS，需要的是**让均值本身下移**，
   而不是把同一个分布测得更细。

换句话说：这两格的问题不在样本量，而在**均值偏离 5.0 的方向是否真实**。
上一轮我把它们读成"只差一点点、去查机制"，并据此提议打破共线的新协议——
那个提议的依据（`corr(面板 MAP, 每搏容积) = −0.995`）是成立的，
但它解释的量（0.15/0.05 mmHg）**比任何可行实验能分辨的下限还小**，
所以排序错了，已撤回为"暂缓"（见 §4 第二档第 3 条）。

## 2. 三条 SBP 偏置预测变量：全部否证

P5/P7 的 SBP 均值超线 0.15 / 0.05，看起来"只差一点点"——**但按 §1.2 它们其实是判不了的**。
改成"未判定"之后为什么还要试公式？因为真正值得修的不是那 0.15，而是**背后的形状**：
**SBP 偏差几乎完美地跟着面板 MAP 走**
（`tmp/sbp_bias_vs_panel_map_20261115.py`，`corr = −0.893`，面板 MAP < 120 的五档平均
**+3.01**、≥ 120 的两档平均 **−3.03**，差 6.04 mmHg）。
这是一个**形状问题**——同一个穿越比例施加在峰位不同的包络上——值得试"一条公式"。
三条都试了。**结论不是"三条都失败"那么干脆**（2026-11-15 晚复核后修正）：
面板 MAP 那条在**正确符号**下全库 7/7，但在唯一留出层上变差；
另外两条确实失败。共同点是**没有一条能通过可迁移性检验**。
（下面表格里 P5/P7 仍按"是否满足 |mean| ≤ 5"标 `f`，
那是拟合口径的机械结果；**判定口径应看 §1.2 的"未判定"**。）

### 2.1 面板 MAP 的线性规则（`tmp/sbp_linear_rule_sign_check_20261115.py`）

### 2.2 包络峰幅度（`tmp/sbp_amplitude_rule_20261115.py`）

判据：模拟器每搏容积随血压降低而变大（0.55 cc @255/195 → 0.75 cc @60/30），
幅度应能代理这个量，且它是**每轮实测**而不是读标签。

- 池化 `corr(幅度, SBP 误差) = −0.208`（n=308）；逐档 −0.397…+0.190，**方向不一致**。
- 诚实拟合 `SBP_error = +0.570 + 103.98·(amplitude in V)` → 过档数 **4/7**，与无规则（4/7）相同；
  P5 +5.15→+6.82 f、P7 +5.05→+6.87 f。留一预设斜率 +63.7k…+305.5k（不稳）。

### 2.3 估出的脉搏压（`tmp/sbp_pressure_rule_20261115.py`）

判据：固定比例法问的是"包络降到一半的地方在哪"，误差应随包络在压力轴上的宽度缩放，
而脉搏压 `PP = SBP − DBP` 正是这个宽度的直接读数。

- 诚实拟合 `SBP_error = −13.374 + 0.32219·PP` → **过档数 4/7 → 5/7 `['1','3','4','5','6']`**，
  P5 +5.15→+2.91 P、P6 +2.82→−0.40 P —— 这是三条里唯一**看起来有救**的。
- **但代价是 sd**：池化 sd **7.27 → 8.50**（越过 8.0），P7 仍 `+4.68/8.49 f`，
  P1 sd 5.75→7.61、P3 5.23→7.48、P4 5.38→7.12 全部变差。留一预设斜率 −22.4…−11.3。
- 判断：它把**均值**挪对了，代价是把**离散度**放大 1.2 倍。在一个 sd 余量只有 10% 的
  语料上，这不是可接受的交易。

### 2.4 而且这三个变量的身份本身是混淆的（`tmp/sbp_bias_confound_20261115.py`）

| 相关系数 | 值 |
|---|---|
| `corr(面板 MAP, SBP 偏置)` | **−0.893** |
| `corr(每搏容积, SBP 偏置)` | **+0.883** |
| `corr(面板 MAP, 每搏容积)` | **−0.995** |

七个预设是**设计上**让 MAP 与每搏容积一起动的（手册 Table 3-2 的容积随血压降低而增大）。
所以"偏置跟着 MAP 走"和"偏置跟着每搏容积走"在这批数据上**无法区分**，
任何以其中之一为自变量的规则都只是在拟合一个共线混淆。
要证伪它，需要**打破配对的新预设**（同 MAP、不同容积，或反之）——现有七档做不到。

### 3.3 改不动：单次 sd 是台架属性

`data/reports/measurement_precision_20261112.md` 早已量过：同一轮内逐搏奇偶二分两半差
sd 34.14、固件包络二分 19.08、逐搏 bootstrap 21.3 —— **轮内 ≈ 轮间**。
所以堆轮次只能压均值，不能压 sd；k 次中位能压（`1.2533σ/√k`），
但 **k=4 只在 Preset 1 通过前瞻验收**（P4 判定 FAIL），且 P2 的 between-day floor
已经 **9.37 > 8**，**即使同一天测无穷多轮也过不了**。

**第二档：需要台架在线 1–2 天**

3. ~~补采 P5/P7 的 SBP：要用**打破共线**的方式采~~ —— **已暂缓，理由见 §1.2**。
   这条原本提议：在同一档内改变每搏容积以外的变量，让 §2.4 的
   `corr(面板 MAP, 每搏容积) = −0.995` 解开。复查后不做的三条理由：
   - 它要解释的量（超线 0.15 / 0.05 mmHg）**比它能分辨的下限还小**——
     功效分析（`tmp/collinearity_test_power_20261115.py`）显示两假设相距 8.0 mmHg，
     2σ 需 4–6 轮/臂、3σ 需 8–12 轮/臂，技术上 30–60 分钟可做；
     但即使做出来，也只是把"偏置跟 MAP 还是跟容积"钉清楚，
     **不改变这两个格"未判定"的结论**。
   - 台架能用的替代预设（手册 Table 3-3 Patient Condition）虽然把
     `corr(MAP, 容积)` 降到 −0.235，唯一同压力配对 Healthy/Obese **心率同时差 15 bpm**
     （75 vs 90），等于拿一个混淆换另一个同类混淆。
   - `tools/covered_bp.py` 的 `BAND_HZ = (1.0, 2.0)` = 60–120 bpm，依据是"面板 Standard
     预设恒 80 bpm"，而语料里没有一轮不是 80 bpm；Table 3-3 八条里
     Strenuous(162)/Tachycardia(130)/Bradycardia(45) 三条落在带外，
     用它采数据等于在估算器设计域外开新域，一旦重验带通，v9 个常量整套跟着动。
     唯一干净的仪器是手册 2-5 的 **User Defined Simulation**（四字段独立、Pulse 步进 0.1 cc），
     但它**没有远程命令、只能手持输入、且无回读**。
   - 更值钱的问法：**这个偏置能不能迁移到别的台架**。脉量是面板设置、真实设备不知道，
     所以"偏置跟脉量走"即使证实，也只是描述我们自己台架的残余，无法变成校正项。
4. **线性规则：方向弄对之后仍然不能用（2026-11-15 晚更正）**。三条候选（面板 MAP / 幅度 /
   脉搏压）在**正确符号**下的实测见 §2.1：面板 MAP 那条全库 **7/7**，但它在唯一留出层
   `v3_acceptance` 上把偏置从 −3.07 推到 **−4.73**，且逐档相关全为正而池化相关为负（辛普森）；
   幅度那条 4/7（等于无规则）；脉搏压那条 5/7 但 sd 7.27→8.50 越线。**结论不变：不要再试
   线性规则**，但理由要改成"没能通过可迁移性检验"，而不是上一版写的"方向反了"。

## 5. 能写 / 不能写

**能写**
- 308 个已发布轮上 21 个 档×量 格子里 17 个满足 AAMI 的 |mean| ≤ 5 且 sd ≤ 8。
- **P5/P7 的 SBP 均值那两格是"未判定"而不是"超限"**：+5.15/5.09（n=39，95% CI
  [+3.50, +6.80]）与 +5.05/6.46（n=36，95% CI [+2.86, +7.24]），两个区间**都含 5.0**；
  超线量只有 0.18 SE 与 0.05 SE。
- 三条 SBP 偏置预测变量（面板 MAP、包络峰幅度、估出脉搏压）**都没有通过可迁移性检验**
  ——面板 MAP 那条在正确符号下全库 7/7 却让 `v3_acceptance` 的偏置 3.07→4.73，
  幅度那条 4/7（等于无规则），脉搏压那条 sd 7.27→8.50 越线。
  （2026-11-15 晚更正了上一版"4/7→3/7"的符号错误，见 §2.1。）
- **SBP 的误差主要是脉压的 2/3**：`e_sbp = e_map + (2/3)·e_pp − note_gap` 在 126/308 轮精确
  成立（最差 0.667 mmHg），MAP 本身已在预算内（池化中位 |误差| 3.04），而
  `PP_est` 对 `PP_panel` 的斜率只有 **+0.657**（脉压被压缩）——但档内噪声 7.02 ≈ 档间跨度 7.6，
  三个视图 SNR 0.41–0.98，**反压缩实测 0/7、sd 6.27→12.49**；
  `SBP = 3·MAP − 2·DBP` 也 **0/7**（sd 翻 2–2.9 倍）。
  详见 `data/reports/sbp_levers_after_unresolved_20261115.md`。
- 唯一能把七档推到 7/7 的是**加性偏移**（−0.5 mmHg 即够，sd 一位不动），
  但开发集 **+2.00** 与留出层 **−3.07** 符号相反，**不是可迁移常数**。
- 面板 MAP 与每搏容积在七个预设上 `corr = −0.995`，两者对 SBP 偏置的解释力无法区分。
- 日间方差占 8–30%（SBP），摊天数只降均值 SE、不降单次 sd。
- P2 的三项 sd（13.4–15.9）**不是算法极限**：退掉两轮面板未确立的轮 + 补采两轮后，
  P2 变成 `−0.29/4.39`、`−1.46/6.29`、`+1.37/3.95` 三项全过（297 轮同一代固件）。

**不能写**
- 不能写"精度已经到极限"——P2 的 3 个 FAIL 是采集缺陷不是算法极限，已用重采证明。
- **不能写"P5/P7 的 SBP 不达标"**——只能说"在这 39/36 轮上无法判定是否超过 5.0"；
  也不能写"再采几十轮就能判出来"：观测均值本身在门槛上方，加轮次只会让区间
  围绕它收窄（半宽减半需 ≈150 轮），不会跨到门槛下方。
- 不能写"P5/P7 的 SBP 偏置改不动"——只能说"三条候选否证"，第四种可能还在。
- **不能写"线性规则把覆盖从 4/7 提到 7/7 是改进"**——正确符号下确实 7/7，
  但它在唯一留出层 `v3_acceptance` 上把偏置从 −3.07 推到 −4.73，且逐档相关全为正、
  池化相关为负（辛普森）；它编码的是档位身份不是物理。
- **不能写"把 `SBP_OFFSET_MMHG` 改成 −0.5 就能达标"**——那只让这 308 轮的数字过线，
  开发集（+2.00）与留出层（−3.07）符号相反；改冻结常量属于 freeze 级决定。
- **不能写"反压缩 / 用 MAP 与 DBP 反推能救 SBP"**——两条实测都是 0/7。
- **不能写"零点修正能解决 SBP 偏置"**——上限 3.74 mmHg，re-zero 后判定仍 5/7。
- 不能写"按天摊开采样就达标"——它不动 sd。
- 不能写"P2 是靠剔数据过掉的"——它是靠**重采**（2 轮新数据）+ 标签处置，
  且 `covered_bp.py` 的默认口径没有改，`--exclude-panel-unknown` 是可选视角。
- 不能把面板 MAP 当成偏置的**原因**——它与每搏容积共线。
- 不能用这七个预设下关于"偏置跟容积"的结论——配对没打破。
- 不能引用"(此前记录) `[SIM_NEO*]` 全部 NAK"——2026-11-15 的 ACK/NAK 控制实验
  实测 `[SIM_NEO35_15]` 返回 ACK，旧记录已作废。
