# 放气闭环的极限环：改了一个控制窗，量了代价，退回原样（2026-11-14）

## 0. 一句话结论

固件的放气闭环**确实在抖**，而且抖动的成因是结构性的：它用 1 ms 的整数脉宽去追一个
1.8 mmHg/s 的目标，而**相邻两档脉宽之间隔着 1.2–3.8 mmHg/s**，死区只有 ±0.4。于是闭环只能
在相邻两档之间来回跳，跳出来的就是压力上 0.8–1.6 s 的极限环（就是 Preset 5 包络里那个
160–210 mmHg 的"隆起"）。

把控制窗从 400 ms 加长到 2000 ms 并改用窗均值测速，**交替确实消失了（逐脉冲变化率 30–48% → 8%）**，
但振荡没有消失：它变成每 10–20 个脉冲换一档的**慢摆动**，峰窗压力纹波反而从 **2.5–4.4 mmHg 涨到
7.2–9.8 mmHg**。所以改动被**回退**，固件回到 `61ca1da3…` / 184146 B。

回退的决定不是因为"改坏了"，而是因为补做的一项检验**没能证明抖动值得修**：在 240 轮旧固件数据上，
峰窗纹波与冻结 v2 的误差相关系数只有 **MAP +0.045、SBP +0.071、DBP +0.229** —— 纹波小的轮并不更准。

## 1. 为什么会抖：三条实测

### 1.1 一个阀脉冲就让测得速率跨过死区

`main.c:2142-2170` 每 `DEFLATE_CONTROL_INTERVAL_MS`（400 ms）算一次速率，用的是**单点采样差分**：

```c
float dt = (now - s_deflate_last_time_ms) / 1000.0f;
float actual_speed = (s_deflate_last_pressure - g_last_pressure_mmhg) / dt;
...
if (err < -0.4f) { s_deflate_pwm_on_ms += 1U; }
else if (err > 0.4f) { s_deflate_pwm_on_ms = (s_deflate_pwm_on_ms > 1U) ? (s_deflate_pwm_on_ms - 1U) : 1U; }
```

400 ms 里只含**两个**阀脉冲（周期 200 ms），而 `g_last_pressure_mmhg` 是 25 ms 一个的**单点**。
按 286 轮实测（`tmp/controller_quantisation_20261114.py`）：

| 测量口径 | 速率 sd | 量化台阶 | 台阶 ÷ 死区 0.4 | 能否收敛 |
|---|---|---|---|---|
| 400 ms 单点（现行） | 2.30 | 1.03 | **2.57** | 不能 |
| 400 ms 均值 | 1.83 | 1.03 | 2.57 | 不能 |
| 1200 ms 均值 | 0.34 | 0.34 | 0.86 | 勉强 |
| 2000 ms 均值 | 0.15 | 0.21 | 0.51 | 勉强 |
| 3000 ms 均值 | 0.11 | 0.14 | 0.34 | 可以 |

（快工作点 `flow ≥ 0.115`，78 轮；慢工作点同趋势但数值更小：1.05 / 0.91 / 2.27。）

单点 400 ms 口径的速率 sd 是 2.30 mmHg/s，**比量化台阶还大 2 倍** —— 因为 1.33 Hz 的模拟脉搏
峰值斜率约 10 mmHg/s，两个单点之差量的主要是脉搏，不是放气。

### 1.2 1 ms 的脉宽步长本身就跨了整个死区

全库 231 份导出按脉宽分箱测单脉冲释放量（`tmp/flow_vs_width_all_20261114.py`）：

| 脉宽 | 单脉冲释放量 | 隐含速率 | 每 1 ms 台阶 |
|---|---|---|---|
| 2 ms | −0.0071 mmHg | 0.78 mmHg/s | — |
| 3 ms | 0.0521 | 1.99 | +0.85 |
| 4 ms | 0.0994 | 3.62 | +1.21 |
| 5 ms | 0.1448 | 8.02 | +1.63 |
| 6 ms | 0.2674 | — | +4.40 |

目标 1.8 mmHg/s 落在 3 ms（1.99）与 4 ms（3.62）之间 —— **没有任何一个整数脉宽能命中**。
慢工作点（flow 0.0889）下 4 ms 恰好给 1.78，是唯一例外；快工作点（flow 0.1346）下 3 ms 给 2.02、
2 ms 给 1.44，都不在 ±0.4 内。

### 1.3 于是形成可预测的极限环

闭环只能在相邻两档之间跳，跳的周期由"两档速率的差"和"控制窗长度"决定：慢工作点 4/5 ms 交替 =
8 个脉冲 = **1.60 s**，快工作点 3/4 ms 交替 = 4 个脉冲 = **0.80 s**。这两个数字与实测吻合：

- Preset 5 的 160–210 mmHg 隆起周期 **1.57–1.62 s**（`data/reports/low_preset_sweep_20261113.md`）；
- 阀脉宽序列的重复图案 `4 4 3 3` / `4 4 5 5 4 4 3 3`，8 脉冲 × 0.200 s = 1.60 s
  （`tmp/hump_valve_width_pattern_20261113.py`，67 轮里 55 轮的脉宽自相关周期与压力振荡周期比值在 0.8–1.25）。

## 3. 量出来的代价：交替没了，纹波大了

### 3.1 逐脉冲交替确实消失

`tmp/pulse_train_20261114.py` 对 `standard120_080_target275_peakwindow_20261114-202311` 的
200–245 mmHg 段：

```
6ms x6 → 5ms x10 → 4ms x10 → 3ms x20 → 4ms x10 → 5ms x20 → 4ms x10 → 3ms x20 → 4ms x10 → 5ms x1
```

每 10–20 个脉冲换一档 —— 2 s 控制窗按设计生效了，每窗只动一次。逐脉冲变化率从上表的
旧固件 30–48% 降到 **8%**。

### 3.2 但纹波涨到 2–4 倍

`tmp/ripple_split_20261114.py`（3 s 滚动中位去趋势 = fast；20 s = slow）：

| 固件 | 轮次 | 峰窗速率 | fast p2p | fast sd |
|---|---|---|---|---|
| 旧（400 ms 单点） | 11-14 上午 9 轮 | 1.78–1.93 | **2.53–4.22** | 0.25–0.43 |
| 新（2000 ms 均值） | `202311` | 1.85 | **8.32** | 0.91 |
| 新 | `204215` | 2.16 | **8.53** | 1.12 |
| 新 | `204552` | 2.00 | **7.16** | 0.82 |
| 新 | `204918` | 2.18 | **9.76** | 1.13 |

原因很直接：一个 2 s 窗内脉宽固定 10 个脉冲，下一窗才改档，于是同样的宽度差**在压力上累积了
10 倍长的时间**。把抖动频率降下来，等于把它变成更大振幅的慢摆动。

同时速率也没变准：新固件 `202311` 1.85（好），但后三轮 2.00–2.18（更差）。

## 4. 关键检验：抖动到底值不值得修

这是决定要不要保留改动的唯一判据 —— "纹波小的轮是否更准"。
`tmp/ripple_vs_accuracy_20261114.py` 把 240 轮旧固件可用轮按峰窗 fast ripple 三分位分组：

| 纹波三分位 | n | 纹波范围 | MAP 误差 | SBP 误差 | DBP 误差 |
|---|---|---|---|---|---|
| 低 | 80 | 0.85–1.69 mmHg | +3.87 / 17.02 | +2.61 / 17.61 | +2.83 / 14.97 |
| 中 | 80 | 1.69–2.58 | +3.13 / 4.71 | +7.95 / 23.39 | +0.13 / 5.29 |
| 高 | 80 | 2.60–8.01 | +4.17 / 9.96 | −0.58 / 22.51 | +8.31 / 13.26 |

相关系数 `corr(ripple, |误差|)`：**MAP +0.045、SBP +0.071、DBP +0.229**；只算 Preset 1 的 83 轮
（MAP +0.049、SBP +0.005、DBP −0.149）。剔除大错轮后（`|e| ≤ 20`，n=213）MAP +0.061、
SBP −0.060、DBP +0.399。

**没有单调关系**：纹波最低的那一组 MAP sd 17.02，比纹波最高那组的 9.96 还差。只有 DBP 有一点
弱正相关（+0.23/+0.40），不足以支撑"改固件能让测量变准"。

补充：`tmp/ripple_vs_dither_20261114.py` 在 Preset 1 的 94 轮上算 `corr(脉宽变化率, fast p2p)`
= **+0.057** —— 连"抖动率 → 纹波"这条链本身都很弱。

## 7. 这一轮证明了什么、没证明什么

**证明了**

1. 放气闭环在 1 ms 脉宽分辨率下**无法收敛**，实测每档台阶 1.2–3.8 mmHg/s 对死区 ±0.4；
2. 加长控制窗能把逐脉冲交替换成慢摆动，但**纹波变大**（2.5–4.4 → 7.2–9.8）；
3. 峰窗纹波与参考算法误差**没有单调关系**（MAP/SBP r < 0.08）—— 所以"减少抖动"不是提高精度的杠杆；
4. 现已发布语料的固件代次可以通过元数据 + Keil 日志严格区分，实验轮次不会污染统计。

**没证明**

1. 没证明"抖动无害"。r ≈ 0.05 只能说在这批数据上看不出效应，不能说原理上不会影响峰位；
2. 没试过**非整数脉宽**方案（固定 4 ms + 调脉冲间隔，25 ms 粒度 ≈ 0.22 mmHg/s），它可能真的能收敛 ——
   但那要改调度器，代价与这次相当，且没有证据表明值得；
3. 没解释清楚 11-14 12:1x 台架流量跳变 +30–57% 的物理原因（阀驱动电压？线圈温升？袖管位置？），
   见 `data/reports/v5_validation_20261114.md` §4。
