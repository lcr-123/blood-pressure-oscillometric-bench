# 拉到底：可行，但"到底"这个数必须先量准

> **容积数字已更新（2026-11-09）**：本文中的 **153 cc** 是用面板每搏设定值反推的
> 估计量，已被直接测量取代 —— 数据集回路实测 **320 cc（区间 278–320 cc）**，
> 见 `data/reports/dataset_loop_volume_result_20261109.md`，交叉验证见
> `data/reports/volume_crosscheck_20261109.md`。**引用容积请用 320 cc。**
> 本文保留作为该数字的来历与误差讨论记录。

日期：2026-11-09
你的意见：不要拉到 20 mL，直接拉到底，避免在 200 mmHg 压力下瞄刻度的出错机会。

## 一、你说对的部分

期待值的四个失败里，**没有一次是公式错**，全部是操作时序或读数：

1. 等 190 秒才推 → P1 过期 19 mmHg
2. 用"压力降 ≥20 mmHg"当判据 → 漏气 190 秒正好 19 mmHg，误触发
3. 先记 P1 再等 → 92.0 等到 70.5
4. 拿 8 mmHg 的"移动"阈值 → 漏气 90 秒就是 9 mmHg，误判

**全都是"在压力下做精确动作"造成的。** 所以"拉到底"这个方向是对的——**它把动作变成硬停止，
而不是瞄准**。

## 二、但有一个新问题：拉到底不是 20 mL

20 mL 针筒的实际全行程容积取决于你推到哪个位置：

| 全行程实际值 | 若按 20 mL 算，容积误差 |
|---|---|
| 19.5 mL | −2.5% |
| **20.0 mL** | 0 |
| 20.9 mL | +4.5% |
| 21.5 mL | +7.5% |

**如果把全行程当成"正好 20 mL"而不去量，容积误差 7.5%** —— 比读刻度 0.5 mL 的 2.5% 还差。

## 三、但"拉到底"和"读刻度"不是二选一

关键洞察：**硬停止的位置可以在无压状态下量。**

1. 回路通大气（`VENT` 后）
2. 拉到顶到底，**在常压下读一次塞子停在刻度哪里**
3. 记住这个数，推回 0

压力下不需要再瞄任何刻度——因为是硬停止，位置自动复现。

| 方案 | 显示误差 | 全行程项 | 合计 | 百分比 |
|---|---|---|---|---|
| 两次瞄准拉（原方案） | 0.74 | 4.40 | **4.46** | 2.5% |
| 一次到底，当 20 mL | 0.74 | 0.00 | 0.74 | **0.4%（假的）** |
| 一次到底，不量（±1.5 mL） | 0.74 | 13.20 | 13.22 | **7.5%** |
| **一次到底，常压下读刻度（±0.5）** | 0.74 | 4.40 | **4.46** | **2.5%** |
| 一次到底，读到 ±0.25 | 0.74 | 2.20 | 2.32 | 1.3% |
| **一次到底 + 水称重标定（±0.2）** | 0.74 | 1.76 | **1.91** | **1.1%** |

**结论：拉到底 + 常压读一次刻度 = 精度和原方案相同（2.5%），但操作容易得多。**
如果愿意再花一分钟做水称重，能到 1.1%，比原方案还好。

## 四、实测全行程 = 26 mL（2026-11-09 已量）

用户在常压下把活塞拉到底，读到 **26 mL**。这改变了所有预期读数，重算如下。

### 4.1 26 mL 是合理的

标称 20 mL 的针筒，筒身到法兰的容积通常就是 **25–28 mL**，而印刷刻度只到 20。
所以 26 mL 正是"推到刻度尽头再往里一点"的物理容积——**进公式的是这个物理容积，不是印刷上限**。

这也意味着：**全行程测试里印刷刻度不再重要**，重要的是实际排开的体积，而 26 mL 正是它。

### 4.2 26 mL 拉力下回路仍在正压

从 190 mmHg 起拉到底：

| 若 V = | 拉后读数 | 落差 | 高于大气压 |
|---|---|---|---|
| 120 cc | 20.8 | 169.2 | 是 |
| 150 cc | 49.7 | 140.3 | 是 |
| **176 cc** | **67.7** | **122.3** | **是** |
| 220 cc | 89.6 | 100.4 | 是 |
| 300 cc | 114.2 | 75.8 | 是 |
| 400 cc | 132.0 | 58.0 | 是 |

**每个候选容积都远高于大气压**，封闭等温假设成立。即使回路是 400 cc，拉完还有 132 mmHg。

### 4.3 更长的力臂让误差更小

| V | 26 mL 落差 | 20 mL 落差 | 每 mmHg 折合 | G±0.5 mL 折合 |
|---|---|---|---|---|
| 150 cc | 140.3 | 111.8 | 1.07 cc | 2.88 cc |
| **176 cc** | **122.3** | 96.9 | 1.44 cc | **3.38 cc** |
| 400 cc | 58.0 | 45.2 | 6.90 cc | 7.69 cc |

**同样的 0.5 mL 刻度误差，现在只带来 1.9% 的容积误差**（原来是 2.5%），因为被更长的力臂稀释了。

### 4.4 修正后的预算

| 方案 | 显示项 | 全行程项（±0.5 mL） | 合计 | 百分比 |
|---|---|---|---|---|
| 一次到底，G=26 | ±1.60 | ±3.38 | **±3.74** | **2.1%** |
| 一次到底 + 水称重（±0.1 mL） | ±1.60 | ±0.68 | ±1.74 | 1.0% |

比原来 20 mL 方案的 2.5% 更好。

### 4.5 你实际会看到什么（预测卡）

从 190 mmHg 起、26 mL 拉到底：

| 若 V = | 屏幕读数 | 判读 |
|---|---|---|
| 120 cc | **21** | 比预估小 |
| 150 cc | **50** | 支持 153 cc |
| **176 cc** | **68** | 支持 153 cc 回路 |
| 220 cc | **90** | 比预估大 |
| 300 cc | **114** | 比预估大 |
| 400 cc | **132** | 罐体可能在回路里 |

> **如果拉完屏幕还在 140–160，说明活塞其实没拉动**，别继续，先确认塞子是不是真的到底了。

### 4.6 一个几乎免费的自检

26.0 mL 水在 25 °C 称重是 **25.9 g**。
- 称出来接近 26 g → 26 mL 是真的全行程 ✅
- 明显不到（比如 21 g）→ 26 这个读数是**刻度读错**，不是真实行程，要换数

## 五、水称重标定（一次性，一分钟）

用 0.1 g 精度的秤（厨房秤可能不够，需要 0.1 g）：

```
一次全行程抽的水      全行程容积
   20.0 g         →   20.1 mL
   25.9 g         →   26.0 mL   ← 你的读数应该是这一档
   27.0 g         →   27.1 mL
```

注射器是一次性耗材，**标定一次就永久适用**。

## 六、单次拉到底的代价：没有交叉校验

两次拉有两条方程，读错会表现为互相矛盾（刻度错 0.5 mL → 两方程差 18 cc）。
**一次拉只有一条方程，没有东西可以对。**

两个替代校验：

### 校验 1：往返（推荐，成本为零）

拉到底、等、读数 → **推回 0、等、再读数两次**。

**注意：压力"回到原线"这个判据本身不成立**，我第一版写错了。原因是漏气与压力相关——
低压时漏得慢，所以按恒定速率外推会**高估**压降，让回推后的读数看起来偏高，而这正是
"进气"会造成的同一个方向。所以**不能用压力差本身判密封**。

真正能判的是**回推后的漏气速率**：

| 回推后速率 vs 初始速率 | 判读 |
|---|---|
| **不高于初始速率** | **PASS**：低压下漏得更慢是固定漏孔的表现，说明没有空气从活塞边缘进来 |
| 高出 0.5–1.5 mmHg/min | WARN：边缘情况，数字重要就重测 |
| **高出 1.5 mmHg/min 以上** | **FAIL**：低压反而漏得快，不可能是同一个漏孔，是活塞边缘进气。换注射器重做 |

这个判据是**物理上单调的**：同一个漏孔在 168 mmHg 一定比在 190 mmHg 漏得慢。
如果实测相反，只能是新开了一条通路。

### 校验 2：每态读两次（不可省）

拉到底之后只读一个数，漏气就会直接进入结果。实测例子里这个修正值 **25 cc（15%）**。
所以每态必须读两次、间隔 60 秒。

## 七、修正后的动作（6 个读数，约 8 分钟）

| 时刻 | 动作 | 记录 |
|---|---|---|
| 加压前 | 常压下拉到顶到底，**已量得 26 mL**，推回 0 | **G = 26 mL** ✅ |
| **T+0** | `<START>` | — |
| **T+90** | 读 | **P0**，t0 |
| **T+150** | 读 | **P0b**，t1 |
| **T+150–155** | **拉到顶到底**（不用瞄），夹住，松手 | — |
| **T+240** | 读（预期约 68，若还在 140–160 说明没拉动） | **P2**，t2 |
| **T+300** | 读 | **P2b**，t3 |
| **T+300–305** | **推回 0**，夹住，松手 | — |
| **T+390** | 读 | **P3**，t4 |

| 之后 | `VENT` | — |

**报给我：P0/P0b/P2/P2b/P3/P3b、六个时刻、当地气压。**（G=26 已经知道了）

## 八、分析工具已改好

```
python tools/valvefree_volume_analysis.py \
    --p0 190 --p0b 184 --t0 90 --t1 150 \
    --p2 68  --p2b 62  --t2 240 --t3 300 \
    --p3 170 --p3b 164 --t4 390 --t5 450 \
    --g-pull 26 --g-sigma 0.5
```

功能：
- `--g-pull` 填实测全行程 26，`--g-sigma` 给它的不确定度（读刻度 0.5，水称重 0.1）
- `--p3/--p3b/--t4/--t5` 往返校验，**按回推后的漏气速率判**（不是按压力差）
- 分别列出显示项、全行程项和合成误差，并指出哪一项主导

用 G=26 跑过示例（P0=190、P2=68）：显示贡献 **±1.73 cc**、全行程（±0.5 mL）贡献 **±3.91 cc**，
**合成 ±4.28 cc（2.1%）**。若改成水称重（±0.1 mL），合成降到约 ±1.9 cc（0.9%）。

## 九、一句话总结

**拉到底是对的，26 mL 是实测值，不是猜的。** 剩下的就是按表读 6 个数。
长力臂还顺带把精度从 2.5% 提到 2.1%，加上往返校验，单次拉比原来的两次拉更简单也更准。
