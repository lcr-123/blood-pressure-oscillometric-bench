# 回弹方向：我上一轮说反了，而且这个错误能毁掉整个测试

## 一、先纠正

**我上一轮说"压力把活塞往内推"——错了。**

**注射器里的气在针头端和活塞面之间，压力升高会把活塞往外推。**

| 我上一轮说 | 正确 |
|---|---|
| 压力把活塞往**内**推（往推到底的方向） | 压力把活塞往**外**推（往容积变大的方向）|

**力的大小没错（150 mmHg 下约 0.64 kgf），方向反了。**

## 二、为什么这个方向错得很致命

**活塞不受约束会往外飘，容积越飘越大。**

在 178 cc 回路、150 mmHg 下，活塞外飘会怎样：

| 活塞外飘 | 新表压 | 表观变化 |
|---|---|---|
| 0.5 mL | 147.5 | **−2.5** |
| 1.0 mL | 144.9 | **−5.1** |
| 2.0 mL | 139.9 | **−10.1** |
| 5.0 mL | 125.1 | −24.9 |

**真实漏气 120 s 只让压力掉约 6.5 mmHg。活塞飘 1 mL 就额外造成 5 mmHg，误差 80%。**

**连 0.5 mL 都影响显著。**

**而且我原来建议的"用顶住法兰的垫块"是无效的** —— 因为那个间隙是**变大**的，垫块反而失去约束。

**有效的锁定方式**：夹住推杆、用拉力方向的扎带、或把推杆头**顶在固定面上让桌面承受推力**（不是垫在中间）。

## 三、所以换个方法：不需要锁活塞

**"加压定容积 + 保压 120 s"这个设计对活塞稳定性太敏感。换成压力阶跃法。**

### 原理

1. 密封在已知压力 **P1**
2. 拉出已知容积 **dV**（20 mL）
3. 读新压力 **P2**

等温气体定律：

```
P1 × V1 = P2 × (V1 + dV)

→  V1 = P2 × dV / (P1 − P2)
```

**活塞只需要保持几秒钟**（等压力稳定），这个手能稳住。
**之前"手按不住"的问题是针对 120 s 保压，不是 3 秒读数。**

### 各起始压力的落点

用 V1 = 158 cc、dV = 20 cc 推算：

| P1 表压 | P2 表压 | 安全 |
|---|---|---|
| 120 | 21.1 | ✓ |
| 150 | 47.8 | ✓ |
| **200** | **92.1** | ✓ |
| 250 | 136.5 | ✓ |
| 280 | 163.1 | ✓ |

**120–250 mmHg 起始都能让拉出后的压力落在 15–140 mmHg，避开固件的负压钳位和传感器上限。**

## 四、误差预算

工作点选 P1 = 200 mmHg：

| 误差源 | 对 V1 的影响 |
|---|---|
| dV ±1 mL（刻度读数） | **±5%**（±8 cc） |
| P2 ±0.5 mmHg | ±0.5% |
| P2 ±1.0 mmHg | ±1.1% |
| P2 ±2.0 mmHg | ±2.1% |

**主导误差是注射器刻度读数（几个百分点），压力读数反而很准** —— 因为分母 P1−P2 = 108 mmHg，
1 mmHg 读数误差只占 0.9%。

**刻度误差可以用多点拟合降低**：从 0 → 10 → 20 mL 分步拉，拟合直线而不是两点差。

## 五、这个方法自带一个不需要真值的自检

**从三个不同起始压力各做一次同样的 20 mL 拉出，比较反推出的 V1。**

如果方法自洽，三次应一致；不一致的离散度就是方法误差。

**这是真正的检验**，因为同一套代数在不同工作点上被独立评估了三次。

## 六、为什么这个设计更好

| 项 | 保压法 | 压力阶跃法 |
|---|---|---|
| 需要锁活塞 | 是，120 s | **否，几秒** |
| 受活塞蠕变影响 | 严重（1 mL 就 80% 误差）| **几乎不受** |
| 直接测 V | 否（靠漏率比反推）| **是，直接算** |
| 固件命令 | vent/seal/target/start/seal | 同样，已充分验证 |

## 七、操作步骤（如果你想试）

**每一轮：**
1. `vent`（通气，活塞推到 0）
2. `seal` → `target 200` → `start` → 等 `target reached` → `seal`
3. 我喊"拉"，你把活塞**从 0 拉到 20 mL 并保持几秒**
4. 我记录 P2
5. `vent` 复位

**换 150、250 起始各再做一次，共 3 轮。**

**每次你只需要稳住 3 秒左右，力还会随压力下降而变小。**
