# 带载充气阀单次开闭：再次触发ADS失读

## 条件与执行

用户要求在原配置带电开闭，未增加续流二极管，未声称泵负载物理隔离或独立测量12V。沿用非人体台架。泵PC8从HIGH保持HIGH；本轮没有start/open、target或校准写入，不改固件。经EK-OmniProbe桥接及GUI串口写权限执行。

初态EMERGENCY/USER_STOP来自上一轮人工stop；ADS ONLINE，UART rx_errors0，ADS累计errors1/recoveries1。不清故障、不重启，以计数增量判定。5秒基线100条新鲜样本均est0，原始1320..1322。

仅一次holdopen（PB8 LOW、PC1 LOW、PC8 HIGH）→名义观察250ms→close（PB8 HIGH、PC8 HIGH）。串口观察窗口不是独立GPIO脉宽或机械动作测量。

## 结果：失败

关阀回显之后出现乱码开头的Pressure sample failed status2及Stream read failed。ADS首个新增失败：stage5 / HAL_BUSY2 / reg01 / TIMEOUT0x20 / state0x20 / SR1=0x10 / SR2=0x2 / CR1=0x0801 / GPIOB=0xFFFB / SCL1 / SDA1；errors由1到2，recoveries首错时仍1、恢复后2。UART硬件rx_errors仍0，不代表不存在文本异常。原始行已保留。

本次在没有泵启动命令、估压保持0的条件下，充气阀切换已足以再次触发失读。结合负载12V断开对照未复现，优先调查充气阀负载/继电器/共享供电接地及PB8相关电气耦合。结果不能单独证明线圈反冲、阀已烧毁、继电器损坏或排除受电气状态影响的软件I2C异常；泵未物理隔离，机械状态未独立测量。

## 收尾已确认

首错后停止重复切换。stop成功且独立执行vent；60条连续新鲜VALID近零、跨度2942ms后seal。随后5秒100条样本均est0，PB8 HIGH/PC1 LOW/PC8 HIGH、pump OFF、manual OFF、ADS ONLINE。末态USER_STOP是后续人工停止，不能代替首错原因。负载供电未作改变，未远程声称已断电。
